# Publication figures not distributed

Publication figure files are intentionally excluded from this public replication repository.

- Analytical Figures 1 and 3–7 can be regenerated locally with `python scripts/make_figures.py`.
- The generated `figures/` directory is ignored by Git and is not included in GitHub or Zenodo releases.
- Figure 2 contains contextual municipal aerial imagery and is not redistributed here; it is not a computational input to the quantitative analysis.

This choice does not affect reproduction of the reported numerical results, which are provided through the scripts and archived processed tables.
