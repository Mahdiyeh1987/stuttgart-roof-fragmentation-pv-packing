# Contributing

This repository is primarily an archival replication package for a specific manuscript version. Reproducibility fixes, documentation corrections, and bug reports are welcome.

Please do not overwrite canonical files under `results/` when testing changes. Public reproduction commands write to `reproduced/`, which is ignored by Git.

When proposing a numerical change, state clearly whether it:

1. reproduces an existing manuscript value,
2. corrects a repository implementation issue without changing the paper result, or
3. changes a scientific result and therefore requires a new repository release and manuscript/version note.
