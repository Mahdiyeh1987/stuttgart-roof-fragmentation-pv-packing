# Historical input data

These files reproduce the exact Stuttgart historical input bundle used in the empirical analysis. Their integrity is recorded in `../results/input_file_manifest_sha256.csv`.

The CityGML and NAS data are third-party geodata. They are not covered by the repository MIT code license. See `../THIRD_PARTY_DATA.md` for upstream source/licensing information and attribution requirements.

The NAS filename explicitly states `ohne_Eigentuemer` (without owner information); no cadastral owner information is included in the archived analytical input.
