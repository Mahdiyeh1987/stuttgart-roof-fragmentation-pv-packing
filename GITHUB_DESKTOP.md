# Update the existing GitHub repository to v1.1.0 with GitHub Desktop

This package is an update to the already published `v1.0.0` repository. **Do not create a second repository.**

1. Keep your existing local `stuttgart-roof-fragmentation-pv-packing` repository folder.
2. From this updated package, copy the updated/new files into that existing folder, preserving the same subfolders. Allow replacement when prompted.
3. Open the existing repository in GitHub Desktop.
4. Confirm that the Changes tab shows the v1.1.0 robustness/results/documentation updates. No PNG/JPG/TIF/SVG/PDF publication figures should appear.
5. Commit with a message such as: `Add final robustness checks for v1.1.0`.
6. Click **Push origin**.
7. On GitHub, create a new release/tag `v1.1.0` from the updated `main` branch. Do not delete `v1.0.0`.
8. In Zenodo, create a **New version** of the existing record and archive the GitHub `v1.1.0` release. Do not delete the old Zenodo version.
9. Copy the DOI shown by Zenodo for the new v1.1.0 record into the final manuscript Data Availability Statement and repository reference before submission.

The update intentionally contains no publication image files.
