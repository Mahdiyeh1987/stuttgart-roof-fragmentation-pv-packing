# Publish with GitHub Desktop

This folder is already initialized as a Git repository and contains an initial `v1.0.0`-ready commit.

1. Extract the repository folder from the provided ZIP.
2. Open **GitHub Desktop**.
3. Choose **File → Add local repository…**.
4. Select the extracted `stuttgart-roof-fragmentation-pv-packing` folder.
5. Click **Publish repository**.
6. Recommended repository name: `stuttgart-roof-fragmentation-pv-packing`.
7. Add a short description such as: `Replication code and data for LoD2 roof-facet fragmentation and rooftop PV packing in Stuttgart.`
8. Choose public/private as required. For a manuscript Data Availability link and Zenodo archival, the final release should be public.

After publishing, create a GitHub **Release** named/tagged `v1.0.0`. That release can then be archived in Zenodo to obtain the permanent DOI for the manuscript.
